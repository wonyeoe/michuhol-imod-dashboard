# I-MOD insight

[대시보드 바로가기](https://michuhol-imod-dashboard.vercel.app/)

**인천 미추홀구 버스 데이터를 바탕으로 I-MOD 운영 검토 후보를 탐색하는 대시보드**

공공데이터 활용 AI 데이터 분석 경진대회 프로젝트입니다. 버스 이용 규모와 승차·운행의 시간적 분포, 월별 변동을 함께 분석하고, 그 결과를 지도와 차트로 전달합니다.

## 분석 개요

- **대상:** 인천광역시 미추홀구
- **기간:** 2026년 4–6월, 유효 관측일 90일
- **분석 흐름:** 정류장명 그룹 286개 → 공간 검토 그룹 40개 → 평가 권역 26개 → 예비 후보 6개

비슷한 수요·운행 특성을 분류하고 가까운 그룹을 권역으로 묶은 뒤, 4개 평가 방식의 결과를 종합했습니다. 대시보드는 기존 STEP 1–7 분석 결과 CSV를 시각화합니다.

> 최종 6개 권역은 추가 검토를 위한 예비 후보입니다. 실제 공급 부족이나 I-MOD 도입 효과를 입증한 결과는 아닙니다.

## 주요 화면

| 페이지 | 주요 기능 |
| --- | --- |
| 종합 현황 | 분석 규모와 최종 후보를 지도·목록으로 확인 |
| 시간대별 분석 | 후보별 승차·운행 비중과 월별 패턴 비교 |
| 후보 권역 탐색 | 26개 권역 검색·필터링, 지역별 특징과 평가 결과 확인 |
| AI 분석 및 선정 근거 | 분석 흐름과 최종 후보 선정 이유 확인 |

## 기술 스택

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · Recharts · React Leaflet · React Router

## 로컬 실행

Node.js 22.12 이상에서 저장소 전체를 내려받은 뒤 실행합니다.

```bash
cd dashboard
npm ci
npm run dev
```

빌드: `npm run build` · 테스트: `npm test`
